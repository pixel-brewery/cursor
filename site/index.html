Cursor

Show where people point.

Cursor is a TypeScript SDK for shared pointers in web and Electron apps. See where another participant is pointing, or let an assistant guide someone to a control and run an action your app approves.

A shared pointer, with room for guidance

See who is pointing

Render each participant’s pointer and name in the active view. A registered target lets the receiving app place the pointer on the same control in its own layout.

Guide someone to a control

Register visible controls by ID so an assistant can point to the right place, such as the Settings button.

Run an approved action

Your app registers the handler and decides whether it can run. The host also manages identity, view membership and realtime delivery.

Add Cursor to your app

Attach the browser renderer to your view and register a target. The same renderer runs inside Electron. Angular, React, Vue and Svelte adapters connect it to their component lifecycles.

const attachment = attachCursorSurface({
    surface,
    controller,
});

attachment.registerTarget('settings', settingsButton);
await controller.run({ kind: 'show', targetId: 'settings' });

Try two pointers in a local demo

Use Node.js 24.15 or newer and set up GitHub Packages access before installing dependencies. Open http://127.0.0.1:4317/ in two tabs to see pointers move between them.

git clone https://github.com/pixel-brewery/cursor.git
cd cursor
corepack enable
yarn install --immutable
yarn demo:web
