# Function: CursorProvider()

> **CursorProvider**(`props`): `ReactNode`

Shares a Cursor accessor registry with the React subtree.

## Parameters

### props

[`ICursorProviderProps`](../interfaces/ICursorProviderProps.md)

Cursor features and descendant content. The registry starts empty without features.

## Returns

`ReactNode`

The descendant content within the registry context.
