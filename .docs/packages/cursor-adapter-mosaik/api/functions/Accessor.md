# Function: Accessor()

> **Accessor**(`definition`): (`value`, `context`) => `void`

Associates a class with its custom element tag and public member declarations.

## Parameters

### definition

[`IAccessorDefinition`](../interfaces/IAccessorDefinition.md)

The tag and public members of the element that the class accepts.

## Returns

A class decorator that attaches the definition to the accessor class.

(`value`, `context`) => `void`
